
# 💰 Sistema de Gestão Financeira Pessoal (PHP & SQLite)

Aplicação web desenvolvida para controle financeiro pessoal, permitindo o cadastro de receitas, despesas e o cálculo automático do saldo em tempo real.

## 🚀 Tecnologias Utilizadas
- **PHP** (Back-end e processamento de formulários)
- **SQLite / PDO** (Banco de dados leve e embutido)
- **HTML5 & CSS3** (Interface moderna e responsiva)

## ⚙️ Como Executar o Projeto Localmente
1. Certifique-se de ter um ambiente PHP configurado (como WampServer, XAMPP ou servidor embutido do PHP).
2. Clone este repositório ou baixe os arquivos para a pasta raiz do seu servidor (ex: `www/` no WampServer).
3. Acesse pelo navegador: `http://localhost/sua-pasta-do-projeto/`
